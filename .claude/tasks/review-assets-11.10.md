## Critical Findings

- [x] **C1**: Invalid `write_audit_log` call signature causing HTTP 500 on all form submissions and POST mutations across all four view files (`apps/assets/views/AssetLeaseRental/AssetLeaseContracts.py`, `AssetLeaseSchedules.py`, `AssetLeaseModifications.py`, `AssetLeaseBuyAnalyses.py`). The canonical signature in `apps/core/utils.py:10` is `write_audit_log(user, obj, action, changes=None, tenant=None)`. All 18 mutating call sites pass 6 arguments: `write_audit_log(request.tenant, request.user, "action", "ModelName", instance.pk, f"Message...")`, raising fatal `TypeError: write_audit_log() takes from 3 to 5 positional arguments but 6 were given`. Update all call sites to `write_audit_log(request.user, instance, "action", changes=..., tenant=request.tenant)`.
- [x] **C2**: Cross-tenant User leakage in `AssetLeaseModificationForm` (`apps/assets/forms/AssetLeaseRental/AssetLeaseModifications.py:59,63`) and `AssetLeaseBuyAnalysisForm` (`apps/assets/forms/AssetLeaseRental/AssetLeaseBuyAnalyses.py:71,77`). `requested_by` and `evaluated_by` querysets are set to `User.objects.filter(is_active=True)` without filtering by `tenant=self.tenant`, and both fields are omitted from `reject_foreign`. Users from other tenants leak in dropdowns and foreign users can be associated with local tenant records. Filter by `tenant=self.tenant` and include in `reject_foreign`.
- [x] **C3**: Contract edit and re-calculate actions reset current amortized liability and ROU carrying balances to initial inception amounts (`apps/assets/models/AssetLeaseRental/AssetLeaseContracts.py:351-352`, `apps/assets/views/AssetLeaseRental/AssetLeaseContracts.py:156,204-206`). In `calculate_present_value()`, `current_lease_liability` and `current_rou_asset_carrying_value` are unconditionally reset to `initial_liability` and `initial_rou`. If an active lease has already settled installments, editing contract notes or title wipes out all amortization progress. Only reset current balances if `self.status == 'draft'` or if no payment schedules have been paid/accrued.

## Important Findings

- [x] **I1**: Day-of-month collapse bug in amortization schedule date incrementation (`apps/assets/models/AssetLeaseRental/AssetLeaseContracts.py:459-463`). Clamping `_d` to February length permanently degrades subsequent months' day to 28 instead of returning to 30/31. Store `base_day = (self.first_payment_date or self.commencement_date).day` outside the loop, and use `_d = min(base_day, calendar.monthrange(_y, _m)[1])`.
- [x] **I2**: Undefined design system badge class `badge-purple` in templates and models (`templates/assets/assetleaserental/asset_lease_contract/list.html:135`, `detail.html:19`, `apps/assets/models/AssetLeaseRental/AssetLeaseContracts.py:56,61`, `AssetLeaseModifications.py:51`, `AssetLeaseBuyAnalyses.py:41`). `badge-purple` is NOT defined in `theme.css`. Replace with valid colour-named badge (e.g. `badge-info` or `badge-slate`).
- [x] **I3**: Non-standard utility classes `text-success` and `text-purple` in financial displays (`contract/detail.html:41,271,323`, `schedule/list.html:125`, `modification/list.html:129`, `buy_analysis/detail.html:55,82,133`). Neither class exists in `theme.css`. Replace with valid `theme.css` classes `.text-ok` and `.text-brand`.
- [x] **I4**: Missing audit logging on `asset_lease_contract_calculate` (`apps/assets/views/AssetLeaseRental/AssetLeaseContracts.py:201-213`). Mutating action updates contract in DB but lacks `write_audit_log`. Add audit logging.
- [x] **I5**: Termination and buyout actions do not cancel remaining scheduled installments (`apps/assets/views/AssetLeaseRental/AssetLeaseContracts.py:251-271`, `apps/assets/views/AssetLeaseRental/AssetLeaseModifications.py:238-242`). When a lease contract is terminated or bought out, remaining future payment schedules (`status="scheduled"`) must be transitioned to `status="cancelled"`.
- [x] **I6**: Paid schedules and executed modifications can be deleted without restriction (`apps/assets/views/AssetLeaseRental/AssetLeaseSchedules.py:165-180`, `apps/assets/views/AssetLeaseRental/AssetLeaseModifications.py:191-206`). Disallow deleting settled installments (`status == "paid"`) and executed modifications (`status == "executed"`), returning a warning message.
- [x] **I7**: Unchecked state re-settlement in `asset_lease_schedule_mark_paid` overwriting contract balances (`apps/assets/views/AssetLeaseRental/AssetLeaseSchedules.py:185-215`). Guard against re-submitting `mark_paid` on already paid schedules to prevent reverting parent contract liability to earlier periods.
- [x] **I8**: Flawed salvage tax treatment, horizon logic, and potential division-by-zero in Lease vs. Buy Analysis (`apps/assets/models/AssetLeaseRental/AssetLeaseBuyAnalyses.py:278-281,311-312,333,339-342`). Under straight-line depreciation down to salvage, book value equals salvage so tax should not be applied to 100% of salvage; buyout option should be evaluated at `min(years, lease_years)`; guard loan interest rate calculations against division-by-zero or negative exponents.
- [x] **I9**: Orphan dollar signs and `$N/A` displayed on nullable numeric fields (`contract/detail.html:172,196`, `buy_analysis/detail.html:150,154,162`). Guard nullable numeric values with `{% if ... %}`.
- [x] **I10**: Unbounded `lease_term_months` causing potential DoS and calendar year overflow (`apps/assets/models/AssetLeaseRental/AssetLeaseContracts.py:134-137,421-464`, `apps/assets/forms/AssetLeaseRental/AssetLeaseContracts.py:63`). Add `MaxValueValidator(600)` (50 years max) to `lease_term_months` on `AssetLeaseContract` and validate in form.
- [x] **I11**: Unbounded full-model QuerySets in filter dropdowns fetching heavy text columns (`apps/assets/views/AssetLeaseRental/AssetLeaseSchedules.py:60`, `AssetLeaseModifications.py:68`, `AssetLeaseContracts.py:73`). In filter dropdown querysets, use `.only("id", "number", "title")` and `.only("id", "name")`.
- [x] **I12**: Foreign key traversal in model `__str__` creates latent N+1 vulnerability (`apps/assets/models/AssetLeaseRental/AssetLeaseSchedules.py:124`, `AssetLeaseModifications.py:194`). In `__str__`, guard with `self.lease_contract.number if self.lease_contract_id else ""`.
- [x] **I13**: Schedule generation atomicity and sequence locking (`apps/assets/models/AssetLeaseRental/AssetLeaseContracts.py:406,465-467`). Wrap schedule deletion and schedule creation inside a unified `with transaction.atomic():` block.
- [ ] **I14**: Missing role/admin authorization on contract activation and modification execution (`apps/assets/views/AssetLeaseRental/AssetLeaseContracts.py:216-247`, `apps/assets/views/AssetLeaseRental/AssetLeaseModifications.py:209-265`). Decorate `asset_lease_contract_activate` and `asset_lease_modification_approve` with `@tenant_admin_required`.
