# Review Findings — Quality Management 12.11: Audit Management

Changeset: `e052bfb46552937ccf9713c99c1f4e2d31fca73e...HEAD`
Reviewers: `code-reviewer`, `explorer`, `frontend-reviewer`, `performance-reviewer`, `qa-smoke-tester`, `security-reviewer`

---

## Critical Findings

- [ ] **C1** — `apps/quality/views/AuditManagement/AuditFindings.py:233-242`: `audit_finding_create_capa` crashes with `TypeError` / `IntegrityError` due to mismatched model fields (`problem_description`, `severity`, `target_completion_date`), invalid status `"initiated"`, missing required FK `quality_owner`, and missing `transaction.atomic()`. Fix: Wrap in `with transaction.atomic():`, map to `CapaInvestigation` schema (`issue_summary`, `action_type="corrective"`, `source_type="internal_audit"`, `source_reference=finding.number`, `risk_priority="critical" if finding.severity == "critical" else "major"`, `quality_owner=finding.audit.lead_auditor or request.user`, `lead_investigator=request.user`, `target_closure_date=finding.response_due_date`, `status="draft"`), and link to finding.
- [ ] **C2** — `templates/quality/auditmanagement/audit_program/list.html:175-177` & `apps/quality/models/AuditManagement/AuditPrograms.py:100-117`: N+1 SQL query explosion in audit program list loop: rendering `prog.progress_percentage`, `completed_audits_count`, and `total_audits_count` triggers 4 un-cached SQL queries per row (61 queries for 15 rows). Fix: Annotate `annotated_total=Count("audits")` and `annotated_completed=Count("audits", filter=Q(audits__status="closed"))` in `audit_program_list`, and update `AuditProgram` properties to use annotations when present.

## Important Findings

- [ ] **I1** — `apps/quality/views/AuditManagement/AuditPrograms.py:162-175`: `audit_program_approve` lacks an authorization gate; `tenant_admin_required` was imported but not applied, allowing any tenant user to approve annual audit programs. Fix: Decorate `audit_program_approve` with `@tenant_admin_required`.
- [ ] **I2** — `apps/quality/views/AuditManagement/{AuditPrograms,QualityAudits,AuditFindings,RegulatoryInspectionHosts}.py`: All 4 delete views (`audit_program_delete`, `quality_audit_delete`, `audit_finding_delete`, `regulatory_inspection_host_delete`) omit `@tenant_admin_required`, allowing standard non-admin users to delete compliance records. Fix: Decorate all four delete views with `@tenant_admin_required`.
- [ ] **I3** — `apps/quality/views/AuditManagement/AuditFindings.py:210-223`: Auditor independence violation on finding closure: `audit_finding_verify_close` lacks an auditor independence check, permitting the cited auditee `assignee` to verify/close their own non-conformance. Fix: Enforce `request.user != finding.assignee` and `request.user == finding.audit.lead_auditor or request.user.is_tenant_admin`, and restrict verification to findings in status `("response_submitted", "response_accepted", "verification_pending")`.
- [ ] **I4** — `apps/quality/views/AuditManagement/AuditFindings.py:194-206`: Missing view-level status guard in `audit_finding_submit_response` allows direct POSTs to reopen closed findings back to `"response_submitted"`. Fix: Add guard `if finding.status not in ("draft", "issued", "escalated"):` returning warning redirect.
- [ ] **I5** — `apps/quality/views/AuditManagement/RegulatoryInspectionHosts.py:191,207`: `regulatory_inspection_host_log_request` and `regulatory_inspection_host_fulfill_request` unconditionally redirect to inspection detail, kicking users out of the active `audit_war_room` command center on every request logged or fulfilled. Fix: Check `request.POST.get("source") == "war_room"` or inspect referer and redirect to `f"{reverse('quality:audit_war_room')}?host={host.pk}"`.
- [ ] **I6** — `apps/quality/models/AuditManagement/AuditFindings.py:145-148` & `apps/quality/views/AuditManagement/AuditFindings.py:180-190`: `AuditFinding.delete()` is not overridden to sync parent audit findings counters, leaving `QualityAudit.total_findings_count` and severity breakdown counts permanently stale after finding deletion. Fix: Override `delete(self, *args, **kwargs)` on `AuditFinding` to call `self.audit.sync_findings_counts()` after deletion, and call `audit.sync_findings_counts()` in `audit_finding_delete`.
- [ ] **I7** — `apps/quality/models/AuditManagement/AuditFindings.py:136-140` and `apps/quality/views/AuditManagement/AuditFindings.py:69-72`: Overdue SLA status divergence: `is_overdue` and view query flag findings with `response_submitted`, `capa_in_progress`, or `verification_pending` as overdue despite remediation already submitted. Fix: Restrict overdue check to statuses `("draft", "issued", "escalated")`.
- [ ] **I8** — `apps/quality/forms/AuditManagement/{AuditFindings,AuditPrograms,QualityAudits}.py`: Mass assignment of workflow fields in ModelForms: `status` and `closure_notes` in `AuditFindingForm`; `status` in `AuditProgramForm`; `status` and `outcome` in `QualityAuditForm`. Fix: Remove these workflow fields from `Meta.fields` and set default status in create views.
- [ ] **I9** — `apps/quality/models/AuditManagement/QualityAudits.py:215-228`: Counter synchronization in `sync_findings_counts` executes 5 separate SQL queries per finding save. Fix: Replace with a single `.aggregate()` call with conditional `Count("id", filter=Q(...))`.
- [ ] **I10** — `apps/quality/views/AuditManagement/{QualityAudits,AuditPrograms,AuditFindings,RegulatoryInspectionHosts}.py`: Sequential unaggregated `SELECT COUNT(*)` queries for KPI stat cards across all 4 list views (14 queries total). Fix: Consolidate each list view's stat queries into a single `.aggregate()` call using `Count("id", filter=Q(...))`.
- [ ] **I11** — `apps/quality/views/AuditManagement/AuditWarRoom.py:11-32`: Wasted database query evaluating `total_active_count` which is never rendered, and multiple evaluations of `active_qs`. Fix: Remove dead query and evaluate `active_inspections = list(active_qs)` once.
- [ ] **I12** — `apps/quality/views/AuditManagement/AuditActionTracker.py:17-25`: Dead queries (`escalated_findings`) and in-memory list comprehension over all tenant findings for overdue calculations. Fix: Remove unused query and filter `overdue_findings` at the ORM level.
- [ ] **I13** — `apps/quality/models/AuditManagement/AuditFindings.py:116`: Cross-table default ordering `ordering = ["-audit__planned_start_date", "finding_number_in_audit"]` forces SQL INNER JOIN on all default queries. Fix: Change default ordering to local fields `["-created_at", "finding_number_in_audit"]`.
- [ ] **I14** — `templates/quality/auditmanagement/audit_finding/list.html:47,56`, `regulatory_inspection_host/list.html:50`, `audit_action_tracker.html:40,49`: Banned `stat-icon red` class (Rule 2 / L33): Theme design system strictly supports `blue`, `green`, `orange`, `purple`, `slate`. Fix: Replace `stat-icon red` with `stat-icon orange` or `stat-icon slate`.
- [ ] **I15** — `templates/quality/auditmanagement/audit_finding/list.html:168`, `regulatory_inspection_host/list.html:136,153`, `audit_war_room.html:176`: Non-existent `text-2xs` utility class used. Fix: Replace with standard `text-xs`.
- [ ] **I16** — `templates/quality/auditmanagement/quality_audit/list.html:68-116` & `templates/quality/auditmanagement/audit_finding/list.html:67-107`: Filter dropdowns and pagination links omit parameters (`program`, `org_unit`, `assignee`). Fix: Add missing filter dropdowns and preserve parameters in pagination links.
- [ ] **I17** — `apps/quality/views/AuditManagement/QualityAudits.py:207-218` & `RegulatoryInspectionHosts.py:210-221`: `quality_audit_close` and `regulatory_inspection_host_close` lack role authorization checks. Fix: Restrict audit closure to lead auditor or tenant admin (and ensure no open critical findings); restrict inspection host closure to front/back room leads or tenant admin.
