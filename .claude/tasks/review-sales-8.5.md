## Left open (not defects, deliberately not changed)

- `cpq_render_proposal_html` (`apps/sales/cpq_services.py:453-454`) writes `proposal_rendered_content` and `updated_at` on every call, so previewing a proposal is still a write on an HTTP GET. This is a denormalised HTML snapshot that is meant to track the quote, and I15 named the *status transition* specifically, so I did not widen the change. If the project wants GET to be strictly read-only, that function needs a `persist=False` flag from the preview view — a decision, not a drive-by.
