## Consolidated Critical

- [x] fixed — **C1 — Account hierarchy and `AccountProfile` integrity are bypassable.** `apps/crm/models/CoreData/Accounts.py:59-95` starts cycle traversal at the persisted current chain instead of the proposed parent, does not lock the chain, has no depth bound, and does not validate that the profile's own Party is a same-tenant organization. `apps/crm/forms/CoreData/Accounts.py:29-35`, `apps/crm/views/CoreData/Accounts.py:52-96`, and `apps/crm/admin.py:302-309` also allow profile-less/foreign/non-organization hierarchy paths. Validate the profile Party, require a same-tenant organization parent with a profile, traverse from the proposed parent, lock rows consistently, and cap depth.
- [x] fixed — **C2 — Reporting-line reads can disclose another tenant's person.** `apps/sales/views/ContactAccountManagement/AccountStakeholders.py:105-108` filters the source tenant but not `to_party`; canonical `core.PartyRelationship` and the 8.3 write paths do not enforce same-tenant person-to-person, non-self relationships. Scope reads/admin and enforce the invariant on every write.
- [x] fixed — **C3 — Enrichment values are not field-validated before canonical writes.** `apps/sales/models/ContactAccountManagement/PartyEnrichment.py:28-77` and `apps/sales/services.py:731-800` permit malformed revenue/count values, invalid emails/URLs/phones, credential-like text, and unbounded field values; conversions can raise and write unsafe canonical data. Enforce per-field type/format/length/range checks on proposal and apply.
- [x] fixed — **C4 — Plan edit authorization and save ordering are unsafe.** `apps/sales/views/ContactAccountManagement/AccountPlans.py:93-136`, `templates/sales/contactaccountmanagement/accountplan/list.html:17`, and the form allow members to edit or take ownership of another member's plan; `save()` followed by `save_m2m()` can commit an unauthorized instance and then raise HTTP 500. Enforce owner/tenant-admin policy consistently and use one atomic `save(commit=False)`/`save_m2m()` path.
- [x] fixed — **C5 — Plan opportunities have no enforceable tenant/account invariant.** `apps/sales/views/ContactAccountManagement/AccountPlans.py:38-42,239-240` and `apps/sales/admin.py` accept direct/admin cross-tenant or cross-account M2M links, and detail/export reads trust the M2M. Centralize save-time validation, scope admin choices, and defensively filter reads.
