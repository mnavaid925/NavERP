## The five Criticals (four of them silent)

1. **C1** — `pdv_upload` read `extract_text(raw UploadedFile)` before `save()`; the raw object has no
   `.path`, the never-raising extractor returns `("", NOTE_UNREADABLE_PATH)`, and `pdv_approve` then
   **overwrote the parent's search copy with that empty string** (measured 103 chars → 0).
2. **C2** — `ProjectFolder._is_descendant_of()` seeded `seen` with `self.pk`, so the membership guard
   fired before the equality test and it was **structurally unable to return `True`**. The cycle
   guard was dead, a cycle was creatable through the ordinary edit form, and `_decorate`'s
   `walk(None, …)` then silently dropped the branch from the tree.
3. **C3** — stored XSS: `onsubmit="return confirm('… {{ name }} …')"`. HTML escaping does **not**
   protect an inline-handler attribute (character-reference-decoded before the browser compiles it);
   `|escapejs` is the fix. Lesson **L42**'s **third** recurrence.
4. **C4** — `.svg` on 7.10's allow-list (a **fork** of the house list that added the one scriptable
   extension) + `MEDIA_ROOT` served unauthenticated with `Content-Disposition: inline` → script on
   the site origin for anonymous visitors. 7.10's half fixed; the handler is carried.
5. **C5** — `AuditLog.action` is `varchar(10)` with `choices` `.create()` never validates; a
   23-char action truncates on non-strict MySQL and raises `DataError`/500 on strict. 7.10's
   instance fixed; **25 other sites** (mostly 6.19) carried.

## Method lessons (the ones worth keeping)

- **A lane's coverage claim is not evidence.** Lane 1 recorded the cycle guard as *enforced* and the
  over-length action as the *only* instance repo-wide. Both were false; only a live request and a
  repo-wide grep settled it. **A guard whose only evidence is the code that reads it is not
  verified.**
- **A later lane can be right about the mechanism and wrong about the payload.** Lane 3 found the
  unescaped `confirm()` and graded it Important on an apostrophe payload that merely breaks the
  handler; lane 6 supplied a payload that keeps the injected call *inside* the `confirm(...)`
  argument list and it **executes**. Severity was re-set on evidence, not lane order.
- **My own probe was wrong too.** The first C2 re-probe read "still broken" because it passed `None`
  — **two roots tie on `(sequence, name)`, so `Meta.ordering` picked the *other* project's root**,
  which has no children. Re-run against a verified parent/child pair it passes. **Check the probe
  before believing the result.**
- **Name carried items as carried.** The anonymous `/media/` handler and the repo-wide audit-action
  sweep are cross-module; folding them into a 7.10 fix would have touched 14 modules and read as the
  repo being clean.
- **A fixer's dev-DB repair can be new work.** The fixer's probes POSTed at the dev DB and drifted
  acme's fixtures; it disclosed this and converged acme onto globex's untouched copy via
  `temp/restore_710_acme.py`. Disclose, do not hide.
