### C7's enumeration found a SECOND, LIVE leak in `apps/projects`
`ProjectIntegrationConnectorForm.__init__` rebuilt the `owner` queryset from
`User.objects.filter(is_active=True)` and re-applied the tenant filter itself, discarding the base
class's scoping — so on the `tenant is None` branch it re-opened exactly the hole C7 closes.
Measured: 28 rows across 6 tenant values, and `User.__str__` returns the email, so the dropdown
rendered other tenants' addresses. Reachable — `ixc_create` is only `@login_required` and the
superuser carries `tenant=None` by design. Fixed by **composing** with the inherited queryset
(`.filter(is_active=True)`) rather than replacing it. **Carried as a Module 7 item.**

### Method notes worth keeping
- **Enumerate, don't spot-check, when the blast radius is a shared helper.** C7's probe walks all
  619 `TenantModelForm` subclasses (652 forms modules imported) and asserts the security invariant
  directly: 1130 tenant-scoped fields inspected, 0 leaking. That is what found the projects leak.
- **Two probe errors were mine, not the code's.** (a) A count computed as `total - complement`
  double-counts a row satisfying two OR'd conditions (acme's archive #2 has `location=''` AND
  `status='lost'`), so C4's probe reported a defect the view did not have. (b) "No choice label is
  truthy" trips on Django's `'---------'` blank label. Both fixed by asserting the real claim.
- **`response.context` is `None` in a plain script** without `setup_test_environment()`.
- **`nulls_first=True` over-corrects**: Django emits `ORDER BY started_at IS NOT NULL, started_at
  DESC`, floating *every* never-started row above *every* started one. `-id` is the right key.

## C7 — ESCALATED, not fixed (the important outcome of the day)

The `_common.py` change (`c20ad27e`) was **reverted** (`68ebb8eb`) on measured evidence. Same 4,866-test
corpus, only the base class differing: **19 failures with it, 4 without, 0 introduced by the revert.**
It broke **15 tests across `inventory` (3), `procurement` (6), `projects` (6)**.

Those modules use a deliberate **two-layer** design: layer 1 is a view-level `request.tenant is None`
guard; layer 2 is `_reject_foreign(...)` in `clean()`, which produces the precise *"That record belongs
to another workspace."* message. **Layer 2 needs the queryset NOT pre-narrowed**, because Django
validates `ModelChoiceField` in `Field.clean`, before `Form.clean` — so emptying the queryset
short-circuits at field level and the operator gets Django's generic message instead. My change made
their validation **worse**. Their docstrings even warn against it (`test_initiation_forms.py`:
*"CURRENT, DOCUMENTED behaviour, pinned so a regression is visible either way"*).

**Rule worth keeping: "where does tenant isolation live — form or caller?" is an architecture decision,
not a bug fix.** When a fix for module X would overturn a documented, test-pinned decision in modules Y
and Z, revert and escalate — that is the house rule *carry, don't fold in*, and it is not timidity.

The one **live** leak the sweep found was fixed independently and self-sufficiently (`2cf76bd4`) so it
survives the revert: `ProjectIntegrationConnectorForm` offered 28 users across 6 tenants (emails, since
`User.__str__` returns the email) to a superuser, via an `@login_required`-only view. The measured latent
exposure is now recorded: **859 tenant-scoped fields across 618 forms**.

### Method that made this decidable
- **A git worktree is the cheap way to prove "pre-existing".** `git worktree add temp/_baseline <sha>` +
  run the failing tests there → all 4 failed identically at `44c72ec3`. Far stronger than asserting
  someone else's failure (L45). Remove with `git worktree remove --force`.
- **Compare JUnit XML failure SETS, not counts.** `--junitxml` + `xml.etree` gave the exact
  before/after/fixed/new partition; the console tail had already cut the list off at 12 of 19.
- **A probe that asserts the wrong invariant is a landmine.** The C7 probe now asserts the latent issue
  is *real and non-zero*, which keeps the escalation honest, instead of asserting it was fixed.
