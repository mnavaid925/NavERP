### Two mistakes worth remembering

   outside the `if project is not None` block → `UnboundLocalError` on `gantt_timeline` with no
   `?project=`. The happy path was fine; only the empty state failed. **Always probe the empty
   and junk-param paths, not just the happy one.**
2. **My own comment broke a test.** The 7.2 leak test greps rendered HTML for `confirm('...')`;
   my template comment *describing* that pattern contained a literal `confirm('...')`, so the
   regex matched the comment and the literal had no digit. Also: 7.8's new bulk confirm was a
   digit-free static literal — fixed by assembling it in JS from the selection count (better UX
   and name-free).

### Durable lessons added to SKILL.md gotchas 15–16

- **A derived property using `.filter()` bypasses the prefetch cache.** Only `.all()` reads it.
  `obj.is_manually_blocked` and `obj.checklist_progress` both re-query; compute off the
  prefetched list in the VIEW instead.
- **`Prefetch("a__b")` costs two queries; a chained `Prefetch("a", queryset=A.objects.select_related("b"))`
  costs one.**
