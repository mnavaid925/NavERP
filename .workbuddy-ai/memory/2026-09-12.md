### Repeat-offender lesson reinforced

**A wrongly-signed numeric seed literal inside `transaction.atomic()` fails silently and
permanently.** The guard sees "already seeded" from a *previous* good run, so `--flush` + re-seed
looks like it works while writing nothing. Prove a seed by ROW COUNT, never by "exit code 0".
Always add `full_clean(exclude=[...])` to new seed factories.
