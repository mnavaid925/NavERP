Three documents that are easy to confuse

and cost real money when swapped

Issue takes material out of a location for a cost centre, a job, maintenance or a sample. Return to stock — the same document with the direction flipped — puts unused material back on the same shelf.

Return to vendor is neither of those. It ships goods off site and expects a credit note, so it lives on its own document: 6.12 Returns to Vendor. Filing a supplier return here would leave stock on hand nobody can find; filing a shelf return there would chase a credit that was never owed.

Posting never moves stock by itself. It mints a draft stock adjustment, signed for the direction of the document, and the ledger changes only when that adjustment is posted in SCM — one code path writes stock, and it lives in the app that owns it.
