How a run moves

draft → proposed → released

Generate reads every active reorder rule in scope and proposes what is short after netting off stock on hand, open purchase orders and open requisitions. It can be pressed again as often as you like — each press replaces the previous set of lines rather than adding to it.

Release turns the accepted lines into one draft requisition per vendor. Draft is the point: approval routing, the budget check and purchase-order conversion all still run afterwards, so nothing here buys anything on its own.

The ABC class filter is the reorder rule's revenue rank — the uppercase A/B/C that SCM's demand planning assigns. It is not the location's lowercase bin-velocity class, which is a different attribute of a different thing that happens to use the same three letters.
