Nothing else exists. Two things this page must NOT do: 1. Present `rows|length` as the bucket total. `rows` is ONLY the current page slice while `count` and `amount` describe the WHOLE bucket — a filtered page of 15 rows in a bucket of 40 would otherwise read "40 disputes" and silently lose 25. 2. Link to a withdraw() route. The model has the method, the urls module does not have the route, so a {% url %} for it is a NoReverseMatch that kills the page. `bucket_choices` is a CHOICES tuple list like the other *_choices on this lane, so it unpacks as (value, label); the selected value comes from the `bucket` context key, with request.GET.bucket as a belt-and-braces fallback. Pagination uses the shared partial, which replays every GET param except `page` — so the ?bucket= filter survives paging without hand-rolling a query string. {% endcomment %}
