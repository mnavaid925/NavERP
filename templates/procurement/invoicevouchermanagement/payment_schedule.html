Nothing else exists here. Two things this page must NOT do: 1. Render bucket.start / bucket.end bare. The Overdue bucket carries start=None and end=None — the LABEL is what says "overdue" — so a bare date filter would render the string "None" in the card header. Both are guarded, and the bucket is styled as overdue by the ABSENCE of a start date rather than by guessing its `key`. 2. Read the discount as an attribute. `discount_amount` is a METHOD on SupplierInvoice, so it is called as {{ row.discount_amount }} (Django calls callables) — `row.discount_amount` is never a stored column. Bucket `rows` are SupplierInvoice objects, not wrapper dicts: number, vendor, due_date, payment_term, total all come straight off the object. Badge colours are hardcoded against the frozen STATUS_CHOICES keys with a get_status_display fallback and a badge-slate tail. {% endcomment %}
