Lane C is the one lane with NO create/edit/delete route: variances are written by run_match() and the url module declares only matchvariance_list / _detail / _accept (contract line 705). The single form in this lane is therefore InvoiceVarianceAcceptForm, whose one field is `note` (optional, max_length 500) — so this page is an ACCEPT page, not a raise-or-edit page, and it always POSTs to matchvariance_accept. Context is deliberately defensive: `form` and `is_edit` are the pinned keys, and `obj` supplies the pk the accept route needs. Everything is guarded, so the page renders a readable explanation rather than raising if it is ever reached without a variance — the {% url %} for the action is inside {% if obj %} because a NoReverseMatch on a missing pk would kill the whole page. The confirm string interpolates only the integer pk. obj.message and obj.explain() are matcher-generated free text and never reach an event-handler attribute. {% endcomment %}
