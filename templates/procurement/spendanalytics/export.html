A PAGE, not a bare download: a sidebar bullet has to land somewhere a person can read, so the route that renders this template is separate from procurement:spend_export_download, which returns text/csv and no template. The two read the SAME GET parameters, which is why the download button below carries the current filters forward verbatim — a download that silently ignores the filters on screen hands back a different dataset under the same name. HONESTY GATE, non-negotiable and stated on the page itself: this ships CSV download only. There is no live BI feed, no PowerBI connector, no SFTP push, and no scheduled delivery worker. `bi_note` is printed verbatim rather than paraphrased so nobody can soften it into a claim the code cannot back. Every cell in the CSV goes through csv_safe on the way out: supplier names, line descriptions and rule names are user-authored, and a spreadsheet will execute a cell that opens with = + - or @.
