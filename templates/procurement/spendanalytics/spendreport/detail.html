This page RUNS the report live through analytics.compute_report(report) on every GET; nothing on it is cached and nothing on it writes. The three POST verbs (run / snapshot / favourite) and the CSV download are the only state changes reachable from here. Context contract, and NOTHING else exists here: obj, report (the SAME object, aliased), result{summary, columns, rows, chart_type, chart_labels, chart_data} — summary is a LIST of DICTS with keys label + value — columns is a LIST of str, rows a LIST of LISTS aligned to columns, snapshots (QuerySet, newest first), start, end, mixed_currency (bool), currency_rows[{code, label, total, display}], row_cap_note, last_run_at, export_url, snapshot_url, run_url, favorite_url, builder_note, department_caveat. There is no `stats` dict, no `is_admin`, no `can_delete` and no per-snapshot url in the context — the snapshot routes are reversed by name from each row's own pk. NO FX RATE TABLE EXISTS anywhere in the repo (stand-in 3). When the window holds more than one currency the view sets mixed_currency and the page renders currency_rows instead of one bogus converted total. Never add a converted grand total here. department_caveat is printed only when a dimension actually is `department`, because the department axis is a 3-hop nullable chain (requisition org_unit, else the PO ship_to) and is NULL for every PO-less invoice — the breakdown carries an explicit (unassigned) bucket so the rows still add up to the headline (stand-in 4). Every nullable FK is guarded before it is dereferenced: owner, vendor, category, org_unit, gl_account, and each snapshot's generated_by. A None FK inside a FILTER ARGUMENT raises and 500s even though a bare lookup would not (L10). Badges compare the frozen CHOICES keys and always end in a badge-slate fallback; only colour-named modifiers exist (badge-green|red|amber|info|muted|slate) — badge-success / badge-danger / badge-warning render unstyled. Only the system-assigned {{ obj.number }} reaches a confirm() handler; obj.name and every snapshot title are user-authored and never do. Literal apostrophes are escaped as \' — ' does not escape inside an event-handler attribute. {% endcomment %}
