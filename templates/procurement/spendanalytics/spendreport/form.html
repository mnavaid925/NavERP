The form carries exactly: name, description, basis, measure, dimension_1, dimension_2, date_range, date_from, date_to, vendor, category, org_unit, gl_account, min_amount, chart_type, top_n, is_favorite, is_shared. Everything else is system-set and is deliberately absent — tenant, number (auto SPR-#####), owner (stamped from request.user in the create view), last_run_at, created_at, updated_at. Do NOT add inputs for them. This is a GUIDED builder: every axis is chosen from a dropdown the form renders. There is no free-form query language and nothing is inferred on your behalf. Field help is keyed off field.name so it stays correct if the form order changes. Each label is bound to its widget with for="{{ field.id_for_label }}", which is the id Django renders on the input itself. {% endcomment %}

What the report answers, in the words your team would use — “Top suppliers by category, this year”.
{% elif field.name == "description" %}
Optional. Worth writing when the filters below are narrow, so the next person knows what was deliberately excluded.
{% elif field.name == "basis" %}
Invoiced counts recognised supplier invoices; committed counts what is on live purchase orders. On the committed basis a category can only come from a classification rule, because a purchase-order line carries no item link.
{% elif field.name == "measure" %}
What is being counted. Credit memos are already signed negative, so a net spend measure nets them off without any special handling.
{% elif field.name == "dimension_1" %}
The main axis — the rows of the table and the bars of the chart.
{% elif field.name == "dimension_2" %}
Optional second axis. It must differ from the first unless both are set to none. Choosing department adds an explicit “(unassigned)” row: an invoice raised without a purchase order has no department to attribute it to, and dropping those rows would stop the breakdown adding up to the headline.
{% elif field.name == "date_range" %}
The window. Choose “Custom range” to use the two dates below; every other option ignores them.
{% elif field.name == "date_from" %}
Required only when the window is a custom range. It may not be later than the end date.
{% elif field.name == "date_to" %}
Required only when the window is a custom range. The end of the window is exclusive.
{% elif field.name == "vendor" %}
Optional. Narrows the report to one supplier. The list holds only parties carrying a supplier or vendor role in this workspace.
{% elif field.name == "category" %}
Optional. Spend with no category resolves to “(Unclassified)” — the classification workbench is where those get rules written for them.
{% elif field.name == "org_unit" %}
Optional. The department is read from the requisition behind the purchase order, falling back to the order’s ship-to unit, so an invoice with no purchase order has none.
{% elif field.name == "gl_account" %}
Optional. Narrows to a single account — useful for separating addressable spend from rent, tax and payroll postings.
{% elif field.name == "min_amount" %}
Optional floor. Rows below this value are dropped, which is the quickest way to cut a long tail down to what is worth acting on.
{% elif field.name == "chart_type" %}
How the first dimension is drawn. “Table only” skips the chart entirely.
{% elif field.name == "top_n" %}
How many rows to keep, between 1 and 100. The rest are not shown; raise this rather than assuming the tail is empty.
{% elif field.name == "is_favorite" %}
Pinned reports sort to the top of the register.
{% elif field.name == "is_shared" %}
Shared reports are visible to everyone in this workspace. Nothing here is ever visible to another tenant.
