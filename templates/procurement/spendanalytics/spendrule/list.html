How a line gets its category

read top to bottom — the first hit wins
  1. On the invoiced basis, the line's own item category is used when the line points at a catalogued item. Nothing below runs.
  2. Otherwise the active rules are tried in priority order, lowest number first, ties broken by the order they were created. The first rule that matches decides the category.
  3. If no rule matches, the line is reported as (Unclassified) — it is never dropped, so the category breakdown always adds back to the headline total.

On the committed (purchase-order) basis there is no item link to fall back on, so the rules are the only thing standing between a PO line and (Unclassified). Rules set to Invoiced only are skipped on that basis entirely.
