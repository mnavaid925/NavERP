What this board can and cannot do

it chases; it does not sign

There is no button here that signs somebody sign-off for them, and there never will be: only the person named on a row can sign it, an administrator included. What an administrator can do is chase — which puts the request in front of the person who owes it — or, on the row own page, record an exemption with a written reason and their name on it. An exemption is not a signature and is never counted as one.

Chasing is idempotent per person per policy. The alert is linked back to the row that raised it, so a second press finds the existing one and does nothing; that is what the Chased column is showing. There is no mail sender wired anywhere in this system, so the alert IS the chase — it appears in the person Task and Alert Center and on their My Policies page.

A row with no deadline is not on this board. It is still owed, but nobody promised a date for it, so it cannot be late for one — saying otherwise would be inventing a deadline nobody agreed to. Set one on the row if it needs chasing.
