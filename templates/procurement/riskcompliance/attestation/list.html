Why a settled row cannot be edited or withdrawn

a signature is evidence, not a field

A pending row is an assignment, and an assignment can be corrected: somebody was asked to acknowledge a policy that does not apply to them, or the deadline was wrong. A signed row is something else entirely — it is the record that a named person read a named version of a rule on a named day — so it has no Edit button and no Withdraw button, and neither view will accept the POST even if one is crafted by hand.

There is no un-sign and no un-exempt either, for the same reason. A withdrawn signature is not a correction; it is a second, contradictory claim about the same day. If a policy has changed, the honest move is to publish the new version and collect its own sign-offs, which is exactly what the version chain in the policy library is for.
