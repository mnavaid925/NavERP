{% extends "base.html" %} {% block title %}Tolerance Exceptions{% endblock %} {% block content %} {% comment %} 6.12 Receipt Tolerances — the exceptions board. A COMPUTED, READ-ONLY board over every non-cancelled goods receipt line of this workspace, bucketed by the verdict a receipt tolerance policy returns for it. It owns no state and writes nothing: the only action on a row is the one-click hand-off that pre-fills a discrepancy claim. The policy is ADVISORY by design. It colours this board and pre-fills the claim; it never blocks the receipt verb, which belongs to SCM. A line the board calls "over-receipt" was still received — that is the point of showing it here. The buckets are narrowed in the ORM before pagination, so the stat tiles and the page counts always agree; `no_policy` is a tile rather than a bucket because a configuration gap should be visible without being a work queue. Context consumed: object_list (the paginated line page — NOT iterated; `rows` is built from it and is what this template loops), page_obj, q, bucket, bucket_choices, vendors, stats. {% endcomment %}
