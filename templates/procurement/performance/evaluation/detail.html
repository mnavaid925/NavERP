That fact is stated THREE times on this page by design — as a standing warning above the button, inside the button's confirm() handler, and again as a past-tense note once manual_override is already set — because it cannot be undone from anywhere in this module. can_generate is false on a published or archived scorecard (a closed period is closed) and for a tenant-less user. When it is false the button is REPLACED by refusal_reason: a greyed-out control that will not say why is worse than no control at all. Two numbers, computed differently on purpose (see composite below): the 6.16 composite is the weighted mean of every SCORED line; obj.overall_score is SCM's blend of the four dimension columns. Showing both side by side is how an operator sees that generate did what it said. Nullable-field discipline (L10): overall_score, grade, every dimension score, measured_value and score are all nullable, and every read of them sits inside an `is not None` branch — never truthiness, because 0 is a real score. Badge classes are COLOUR-NAMED only (L33). Every score LINE takes its class from line.band_css — the committed BAND_CSS mapping on the model — so a row can never disagree with the model about what "critical" looks like. The band legend below is the one place a literal chain appears: band_choices is a list of (value, label) 2-tuples with no css hook to read, and the four branches there mirror BAND_CSS exactly.
