EVERY obj.* read below is inside an is_edit branch — on create there is no obj and an unguarded read is a silently blank region (L8). Context contract: form, is_edit, and on EDIT ONLY obj. The create view also passes title / submit_label / cancel_url (the costforecast_create page furniture). This page deliberately IGNORES all three and drives its heading, its button and its cancel link from `is_edit` alone — the contract's preferred option — so there is exactly one place the two modes differ and no key that exists on one render and not the other. The form carries thirteen fields: supplier, scorecard, kpi, period_start, period_end, respondent_kind, respondent_function, respondent, respondent_name, rating, importance, due_date, comment. `status` is NOT one of them: the lifecycle belongs to the submit / decline / expire verbs on the detail page, and a typed status would be a claim with nothing behind it. `number` (auto SFB-#####), `tenant`, `requested_by`, `requested_at` and `submitted_at` are system-set and have no input either. Five rules are enforced by the MODEL, not by anything here, and are raised together so this page shows every problem at once: one response per (supplier, period document, KPI, respondent); a chosen KPI must be a survey KPI; the period must not end before it starts; a submitted response needs a rating; and a supplier self-assessment carries a name and no internal user. The help text below explains each of them where the field renders. Field help is keyed off field.name so it stays correct if the form order changes. Each label is bound to its widget with for="{{ field.id_for_label }}". {% endcomment %}

{{ field }} {% if field.name == "supplier" %}
Who is being rated. The list is this workspace’s supplier and vendor parties.
{% elif field.name == "scorecard" %}
The period document this response belongs to. Leave it blank for ad-hoc feedback — but a response tied to a period is the one a scorecard can actually average, because generate reads the responses whose window falls inside it.
{% elif field.name == "kpi" %}
Which survey question this answers. Only active 360-survey KPIs are offered: a derived KPI is computed from the transaction spine and never looks at feedback, so a response attached to one would be filed where nothing reads it — and the model refuses it outright. Leave blank for general commentary.
{% elif field.name == "period_start" %}
The start of the window being rated. Respondents answer about a period, not about today.
{% elif field.name == "period_end" %}
The end of the window. It must not fall before the start — and it is what decides which scorecard period this response is averaged into.
{% elif field.name == "respondent_kind" %}
Internal is what we think of the supplier. A supplier self-assessment is what the supplier thinks of itself, filed on its behalf. Only internal responses feed a KPI’s measured value; a self-assessment is read next to our score, never folded into it — and the gap between the two is the whole point of collecting both.
{% elif field.name == "respondent_function" %}
Which function is answering. A buyer, a quality engineer and an AP clerk see very different suppliers through the same purchase order, and being able to slice the survey by function is what stops one loud department speaking for the whole business.
{% elif field.name == "respondent" %}
The internal user answering, when there is one. Leave it blank for an external respondent — and it must be blank on a supplier self-assessment, which is not filed by anyone on our side.
{% elif field.name == "respondent_name" %}
Required on a supplier self-assessment, which has no internal user account. Otherwise optional — useful for naming an external respondent, or for recording who answered on behalf of a shared mailbox.
{% elif field.name == "rating" %}
1 to 5, and the labels are on the options so a “3” cannot mean “average” to one respondent and “barely acceptable” to the next. Optional here because the ordinary flow is to request now and rate later through Submit — but a response that is submitted must carry one.
{% elif field.name == "importance" %}
How much this answer counts in the weighted mean, 0–10. A response filed at 0 still counts as a respondent and moves the number by nothing, so a page can honestly say eight people answered while reporting that six of them shaped the score.
{% elif field.name == "due_date" %}
When you need the answer by. Optional — but a request with no deadline can never show up as past due, and an outstanding request nobody chases is one nobody answers.
{% elif field.name == "comment" %}
Why the rating is what it is. Optional, and the most valuable field on the form: a number with no sentence behind it is something nobody can act on.
