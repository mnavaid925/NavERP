A KPI is a definition, not a measurement: which number to take, which way is better, where the warning and critical lines fall, and how much it counts. The figures themselves are written onto scorecards when a period is generated.

{% for field in form %}
{{ field }} {% if field.name == "code" %}
The master identifier this KPI is rolled up by across every scorecard — e.g. OTIF-01. Unique within the workspace, and worth keeping stable: changing it later re-labels every report that quotes it.
{% elif field.name == "name" %}
What a buyer would call it in a review meeting.
{% elif field.name == "description" %}
Optional, but the place to settle arguments: exactly what counts, what is excluded, and over what window.
{% elif field.name == "category" %}
Groups the KPI on the boards and on the category filter. It does not affect the arithmetic.
{% elif field.name == "unit" %}
A label for the measured value. Nothing converts between units — a percentage and a day count are simply printed as what they are.
{% elif field.name == "direction" %}
The single most important choice on this form: it is what makes a threshold mean anything. 98% on time is good and 2 days late is bad, and only this field tells the banding which way to read.
{% elif field.name == "source" %}
Derived reads the transaction spine through a named resolver. 360 survey averages the submitted feedback responses against this KPI, weighted by each respondent’s importance. Manual is typed onto the scorecard line.
{% elif field.name == "derived_metric" %}
Required when the source is derived, and must be blank otherwise. The list is closed on purpose: every key here is a promise that a reviewed resolver exists for it, so a KPI can never look like it is computing something it is not.
{% elif field.name == "weight" %}
How much this KPI counts, 1–100. Weights are re-weighted over the KPIs actually scored in a period, so a KPI with no data does not quietly drag the composite down.
{% elif field.name == "target_value" %}
What good looks like. Optional — but linear scoring needs it, and without a target or a critical line the KPI cannot band at all.
{% elif field.name == "warning_threshold" %}
The line where a supplier stops being on target. Must sit between the target and the critical line in the direction you chose above — for a higher-is-better KPI that means target ≥ warning ≥ critical.
{% elif field.name == "critical_threshold" %}
The line where the number becomes a problem to act on. Crossing it is what opens improvement plans and what a band-crossing alert reports.
{% elif field.name == "scoring_method" %}
Band gives 100 on target, 70 at warning, 30 at critical. Linear interpolates between the critical line and the target — and falls back to the band table when there is no usable span between them. Direct treats the measured value itself as the score, clamped to 0–100.
{% elif field.name == "maps_to_dimension" %}
Which of the scorecard’s four weighted columns this KPI rolls up into. Leave blank to measure it without feeding any of them.
{% elif field.name == "applies_to" %}
All suppliers, or one tier only. Tier-scoped KPIs are how a strategic partner gets asked more than a transactional one without inventing a second catalogue.
{% elif field.name == "applies_to_tier" %}
Required when the KPI applies to one tier, and must be blank when it applies to all. Matched against the supplier’s SCM profile tier — a supplier with no profile only ever gets the all-suppliers KPIs.
{% elif field.name == "review_frequency" %}
The cadence you intend to review this on. Stored only: nothing schedules off it, and scorecards are generated on demand.
{% elif field.name == "industry_benchmark_value" %}
Optional, hand-entered reference figure. There is no external benchmark feed in this system — whatever you type here is what the pages will show, so note where it came from in the description.
{% elif field.name == "owner" %}
The person answerable for this number when it moves. Optional, but an unowned KPI is one nobody chases.
{% elif field.name == "display_order" %}
Lower numbers sort first on the catalogue and on every scorecard. 100 is the ordinary default; leave gaps so a new KPI can slot between two existing ones.
{% elif field.name == "is_active" %}
Untick to retire a KPI: it stops being picked up when a period is generated, and every figure ever measured under it stays readable. This is the way to withdraw a KPI — deleting one that has been measured is refused by the database.
{% elif field.name == "notes" %}
Optional. Worth writing when the definition exists for a reason that is not obvious from the fields alone.
