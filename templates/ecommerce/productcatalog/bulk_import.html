CSV Column Format

Your CSV should include the following header columns (order does not matter):

  • Product_Name *required
  • Slug (auto-generated if empty)
  • Brand (optional)
  • Category (optional)
  • Status (draft, active, archived)
  • Visibility (storefront, hidden)
  • SKU (variant SKU)
  • Variant_Name (e.g. Size L)
  • Price (e.g. 29.99)
  • Compare_At_Price (MSRP)
  • Cost_Price (cost)
  • Barcode (UPC/EAN)

Rows with the same product name or slug will be attached as multiple variants to a single catalog product.
