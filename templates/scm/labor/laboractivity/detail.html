No standard matched this activity, so it carries no earned minutes and no performance figure — every measured cell on this page is an em dash rather than a zero. {% comment %} THE SENTENCE. Everything else on this page is a number; this is the paragraph that makes the numbers trustworthy, so it is printed in every measured state rather than only when snapshot_differs is True — a reader who arrives on an unchanged row must already know why the left-hand column exists, or the day it does differ they will assume the page is broken. {% endcomment %}

The left-hand column is why editing the standard later cannot change this row. When this activity was filed, the three determinants above were copied onto it, and the earned figure is recomputed only from those copies and this row's own quantity — it never goes back to the standards library. Re-time a picking standard next March and February's rows keep the numbers they were measured with. Without that, tightening a standard would retroactively turn passing shifts into failing ones, and nobody could reproduce a figure they were shown at the time.

The three inputs are stored beside the total on purpose: a single stored figure would be a number with no visible working. These are the actual operands, so the arithmetic can be replayed from this row alone — months later, after the standard has been retuned, renamed or deleted outright.

A booking is a record of minutes, not a document with a lifecycle, so there is no cancel or void here. Changing the activity type on an existing booking is the one edit that does not fully correct itself: the standard filed for the original type stays in place, because the snapshot is never rewritten after the fact.
