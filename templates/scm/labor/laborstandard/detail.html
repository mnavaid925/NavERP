{% comment %} ========================================================================== 3. where it came from Provenance is not decoration. A supervisor arguing with a number is entitled to know whether it was time-studied on this floor or lifted from a library, and the three answers carry genuinely different weight. {% endcomment %}

Where this number came from

{{ obj.get_source_display }}

{% if obj.source == "engineered" %} Engineered. Built from a method — the task broken into its elements and each element given a time, then assembled into the determinants above. It is defensible element by element, which is what makes it arguable: a supervisor who disagrees can point at which element is wrong rather than at the total. {% elif obj.source == "observed" %} Time-studied on this floor. Somebody stood there with a stopwatch and this is what they measured, on this site, with this equipment and this layout. It is the strongest claim of the four for this scope and the weakest for anywhere else — an observed standard should not be widened to the network without re-observing it there. {% elif obj.source == "benchmark" %} Benchmark library. Lifted from published or industry figures rather than measured here, so it is a starting point rather than a finding: it says what the work takes somewhere, under conditions that may or may not resemble this site's layout, equipment and product mix. Treat a persistent gap against it as a question about the standard first and the crew second. {% elif obj.source == "learned" %} Learned from history. Derived from what has actually been booked rather than from a method. It has a circularity a person has to hold in mind: a standard learned from past performance measures the floor against its own habits, so it tracks drift instead of correcting it. {% else %} {{ obj.get_source_display }}. {% endif %}

Provenance is a claim made by whoever wrote the standard, and it is on the form for exactly that reason — unlike a session's source, which is stamped by whichever code path filed it, because a provenance a user can type is not a provenance. The difference matters when a figure is challenged: engineered and time-studied invite you to check the method, benchmark invites you to check whether this site resembles the one the figure came from at all. A standard nobody can trace is a standard nobody accepts.

{% comment %} ================================================================= 4. the ladder — who beats whom select_standard() walks four rungs, narrowest first, and each rung matches standards scoped to EXACTLY that shape. Which standard wins — the most-specific-wins ladder

This standard sits on rung {% if obj.location and obj.item_category %}1{% elif obj.item_category %}2{% elif obj.location %}3{% else %}4{% endif %}

When work is booked, the resolver asks for the narrowest active standard whose window covers that day and stops at the first rung that answers. A standard on a higher rung beats this one for work that matches its scope; this one beats everything on a lower rung.
