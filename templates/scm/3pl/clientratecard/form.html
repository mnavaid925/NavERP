When it applies

Two active cards for one client may never overlap

Leave the end date blank for an open-ended tariff — blank means "no end", which is the ordinary shape for the card a client is on today, and it is emphatically not read as "already finished". An end date before the start date is refused.
The overlap guard is the rule worth knowing before you meet it: a second active card for the same client whose dates overlap this one is refused, and the message names the card it collided with. A billing run that found two live tariffs covering the same day would have no defined answer about which rate applies, and quietly picking one is how a client ends up billed at prices nobody agreed. Supersede the old card first — its end date is stamped for you — or give this one a start date after the old one closes.
Status is here so a card can be corrected, not as the normal way to move one. The audited route is the Activate and Supersede buttons on the card itself: both are POST-only, both re-run the overlap guard, and both write their own audit record. Rates stop being editable the moment a card leaves Draft, which is deliberate — a run that has already been calculated against these prices has to keep meaning what it said.

Money

The card sets the currency; the lines set the prices
{% include "partials/form_field.html" with field=form.currency %}
Leave the currency blank to fall back to the client's own default. Whatever ends up on the card is what a drafted invoice is raised in, so a card that mixes currencies with its client is a question worth answering here rather than at the point somebody is trying to send a bill. Currencies are a global master shared by every workspace — there is no per-tenant currency table — so the list is short and the same one accounting uses.
Nothing on this page posts to the ledger. A 3PL billing run stops at a draft invoice in accounting; the aging, the cash application, the tax determination and the journal entry are all Module 2's, and duplicating any of them here would create a second set of receivables that could disagree with the first.
