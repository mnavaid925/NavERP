Nothing on this screen writes. The three triage verbs — resolve, reopen and raise a return — live on an inquiry's own page, behind the row lock, because each one changes the answer a customer was given and each writes its own audit row saying who changed it. RMA raised is never something anybody picks from a dropdown: it is a claim about a document, so only the verb that has the return in its hand may set it, and an inquiry badged that way always has a return to click. Resolving twice is refused as a no-op rather than an error — the first answer is the one the customer received, and a second stamp would make “how long did we take?” unanswerable.
