How this preview is worked out

{{ preview_scope_note }}

Availability is derived live from the append-only stock ledger, one grouped query over this page's items — never a stored band. A band is recomputed every time a page renders because on-hand is itself derived, and a stored copy would be stale the moment a move posts, in the direction that tells a customer something is in stock when it is not.

An em dash is not a zero. An item with no rows on the ledger has never been counted, which is a different fact from having none left — the first prints —, the second prints "Out of stock". Printing 0 for the first would tell a customer an item is unavailable when the truth is that nobody has ever counted it.

Nothing on this page can be edited here. The items belong to Inventory and the settings belong to the portal account, so the eye opens the real item one hop away and the header button opens the account's own form. This console holds a read-only projection and no write of any kind.
