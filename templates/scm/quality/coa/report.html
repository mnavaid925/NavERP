No outgoing inspections

Only an outgoing inspection can certify a shipped batch, so only those appear here. Create one against a shipment, flag the characteristics that belong on the certificate, and it shows up as ready once it has passed and been accepted.
{% include "partials/pagination.html" %}

A certificate is never issued over an out-of-specification value. Seven independent rules decide it: the inspection must be outgoing, it must have passed, a usage decision must have accepted the lot, no included characteristic may have failed or be left unrecorded, a lot-tracked item must name its batch, and at least one characteristic must be flagged for the certificate. The column above shows the first that applies; issuing lists every one that still does.
