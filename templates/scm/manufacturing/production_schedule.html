Infinite-capacity on purpose: the board shows where the plan exceeds capacity and by how much, without pretending to resolve it. A finite-capacity scheduler that levels and re-sequences across centres is a genuine solver and a later pass — showing a fabricated feasible plan would be worse than showing an honest overload. A run whose planned window merely overlaps the edge of this window still consumes capacity inside it, so it is counted.
