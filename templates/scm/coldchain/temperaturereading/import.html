What was skipped or dropped

ReasonRowsWhat it means
No readable temperature {{ result.skipped.no_temperature }} The cell was blank or could not be parsed. The row was dropped — never filed as 0 °C.
Unreadable timestamp {{ result.skipped.bad_timestamp }} An interval summary has to state its own window, and a row with no moment has no place in a series.
Dated in the future {{ result.skipped.future }} A future row sorts to the top of an append-only log and becomes "the current value" for a store that has not reached it yet.
Outside the physical bounds {{ result.skipped.out_of_bounds }} Refused rather than clamped. A quietly clamped temperature is a measurement nobody took wearing the costume of one somebody did.
Before this deployment started {{ result.skipped.before_deployment }} The row is dated before the monitor's deployment date. A re-usable logger carries every consignment it has ridden, and those rows belong to the earlier deployment — counted here they would drive this one's time-in-range and MKT.
Duplicate timestamp inside the file {{ result.skipped.duplicate_in_file }} Two rows claiming the same moment on one monitor. The first was kept.
Humidity dropped, row kept {{ result.skipped.dropped_humidity }} The humidity cell was out of 0–100 %, so it was cleared while the temperature — the reading that matters — was imported.
Interval statistics dropped, row kept {{ result.skipped.dropped_interval_stats }} The minimum or maximum did not bracket the reading, so those two columns were cleared rather than the whole row being lost.
Every skip and every dropped value is counted, not silenced. A skip nobody can see is how an import quietly loses a third of a logger file and nobody notices until an audit. Fix the offending rows and upload the file again — the rows that landed the first time will come back as duplicates, not as a second copy.

The header row must name reading_at and temperature. humidity_pct, min_temperature, max_temperature, sample_count and notes are optional; anything else in the file is ignored. Column names are matched case-insensitively with punctuation stripped, and the order does not matter.
Leave the interval override blank and every row is stamped with this monitor's own logging interval of {{ interval_minutes }} minutes. Set it only when the file itself was logged at a different cadence than the monitor is configured for — that weight is what a hot hour counts as in every duration and mean-kinetic-temperature figure derived from these rows, and it is snapshotted once at import so changing a setting next month cannot restate this month's arithmetic.
