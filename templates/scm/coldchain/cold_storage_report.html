How each section is worked out

Cold on-hand
Every stock movement in a bin classified chilled, frozen, deep frozen or cryogenic, summed per item and per location. Rows that net to zero or below are dropped — an empty bin is not a stocking location.
Mismatch
An item that declares a cold class sitting in a bin whose class is different. Exact inequality, both directions, plus “bin not classified” as its own kind.
Expiring
Lots of cold-rated items whose expiry date falls on or before today plus the horizon, excluding consumed lots and lots with nothing left on hand.
Quarantined
Lots of cold-rated items whose status is quarantine. Read only — a non-conformance is what puts a lot there and what takes it out.
Unmonitored
Cold locations with no monitor in the active status pointed at them. Inactive, in-calibration, retired and lost monitors are not cover.
Value
Quantity times the unit cost carried on each movement, summed. It is the ledger's own arithmetic, not a second valuation.

Each section fetches at most {{ row_cap }} rows and says so when the cap bit, so the limit bounds what is read from the database rather than merely what is drawn. The header counts are taken from the same computation as the tables, so a chip and a table on this page can never disagree.

A blank temperature class is never treated as ambient. “Nobody has said what this bin provides” and “this bin is deliberately uncontrolled” are different facts with different fixes, and only one of them is closed by an edit on the location record.
