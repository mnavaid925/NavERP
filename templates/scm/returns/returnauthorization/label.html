{% comment %} THE RETURN SLIP. A standalone document rather than a base.html page, exactly like the other print page in this application: what a customer prints and puts in a box carries no navigation, no sidebar and no action buttons. The toolbar is the only chrome and the print stylesheet hides it. **This is a RETURN SLIP, not a carrier label.** There is no barcode library, no QR library, no PDF library and no carrier API anywhere in this repo, so the return number prints as TEXT. The real label is bought elsewhere and its tracking number is pasted onto the return afterwards. It is reached by the same public token as the status page, and the view refuses to render it at all unless the return is approved, awaiting receipt or partially received — a slip for a return nobody has approved is a document that looks real and is not. **This page grants MORE than the status page does.** It necessarily prints the warehouse return-to address. The two token surfaces are not equivalent and must not later be assumed to be. Everything below is escaped and nothing uses the safe filter: the address and the instructions are typed by a workspace user and rendered to a stranger's browser. {% endcomment %} Return slip {{ obj.number }}
