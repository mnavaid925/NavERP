{% extends "base_auth.html" %} {% comment %} THE PUBLIC RETURN-STATUS PAGE. No login, no session, no tenant on the request — the unguessable token in the URL is the only credential, and the view refuses a draft or cancelled return in the lookup itself so one of those 404s rather than leaking that it exists. It extends base_auth.html rather than base.html — a visitor gets no sidebar, no navigation and no workspace chrome, exactly as the public case and knowledge-base pages do. (The extends tag has to come first in the file, which is why this note sits under it rather than above it.) Three rules govern what may go on this page and none of them is negotiable: 1. NO PRICES, NO COSTS, NO SUPPLIER DATA. The view hands over a purpose-built list of line dictionaries — description, quantity, reason, follow-up question — precisely so that a future edit here cannot reach through the return object and render a cost by accident. 2. EVERYTHING IS ESCAPED. Tenant and customer text is rendered through Django's autoescaping and the safe filter appears nowhere on this page. The policy's portal instructions are typed by a workspace user and land in front of a stranger's browser. 3. BOTH FORMS CARRY A CSRF TOKEN. CSRF is enforced globally in this project — the only exemption anywhere is a payment webhook — and nothing here is exempt from it. {% endcomment %} {% block title %}Return {{ obj.number }}{% endblock %} {% block content %}
