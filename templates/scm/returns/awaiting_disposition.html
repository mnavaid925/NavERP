The bench is clear

Nothing is waiting for a grading decision. Rows land here the moment a return is received — one row per quantity received against a line — and leave it as soon as somebody decides whether the unit is restocked, refurbished, scrapped, liquidated or sent back to the vendor.

None outstanding

A credit-only return asks for nothing back, so it can never appear on a bench queue. When one is waiting to be credited it is listed here rather than being silently absent — real work that structurally cannot show up in the table above.
These returns keep (or never had) the goods and are settled straight from their approved quantities on the refund queue. They are listed here because the bench is the page somebody checks for "what is still outstanding", and a queue keyed on what has physically arrived would drop them without saying so.
