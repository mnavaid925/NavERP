The delivery stamp on a sales order is a manual human action, so on most orders it is never set — the clock then runs from the order date over the fallback window instead. Every return shows the date its verdict actually used, so nobody has to guess which window refused them.

The return-to address is free text on purpose: a warehouse location in this application carries a code, a type and a pick sequence, and no address at all. There is nowhere else the return slip could get one from.

The four grade percentages are part of the policy — edit it to set them.
This ladder is what turns a condition grade from a dropdown nobody reads into money: a B-grade unit comes back into stock at its percentage of the item's average cost, so the valuation report and the weighted-average roll reflect what the thing is actually worth now. The figure is seeded once onto the bench row and then human-owned — a refurbisher who spent real money on parts knows the unit's worth better than a percentage table does, and nothing recomputes their number afterwards. A grade the ladder does not recognise is written down to zero, deliberately: restocking an ungraded unit at full cost is the expensive direction to be wrong in.
