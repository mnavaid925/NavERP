{% comment %} Each paragraph below states a rule the form's own clean() enforces, so the note a configurer reads and the validation that refuses their save cannot drift apart. The grade-ladder paragraph is the one that matters most: it is the only place in the application where a condition grade becomes money. {% endcomment %}

The window. The basis decides which date the clock runs from. A delivery basis falls through to the fallback far more often than it looks — the delivery stamp on a sales order is a manual human action, so on most orders it is simply never set and the clock runs from the order date over the fallback window instead. A zero-day window on both the basis and the fallback accepts no return at all, and the save is refused. Turning on delivery confirmation required will refuse a lot of honest returns for exactly the same reason — that stamp is nobody's habit.

The money. A percentage refund basis needs a percentage above zero, a configured restocking fee needs a value above zero, and a percentage fee cannot exceed 100% — all three are refused on the form. The fee is netted inside the credit note as a negative line, so a fee that meets or exceeds the value of the return would produce a credit note that can never be posted or paid; the settlement action refuses to draft one and asks for the fee to be raised separately in Accounting.

The grade ladder is the whole reason this table exists. A returned unit is posted back into stock at its grade's percentage of the item's average cost — never at what the customer paid, which would roll the item's weighted average up toward the selling price and overstate inventory value. The ladder should fall as condition falls; a B-grade worth more than an A-grade is flagged on the field, because it would write returns up in value. The figure is seeded once onto the bench row and is human-owned from then on.

Selection and precedence. A category-specific policy beats a blanket one, the lowest priority number wins among equals, and the default flag is the last resort. Auto-approve never approves anything — it pre-ticks the approval form, and every approval still stamps who pressed it. The return-to address is free text because a warehouse location in this application has no address field; it is what the return slip prints.
