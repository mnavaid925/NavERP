Nothing owed

A return reaches this queue once it is past the request stage and either has goods dispositioned into a credit-bearing outcome or is a credit-only return with an approved quantity. Approve a return and disposition what comes back, and the settlement appears here computed from the lines.
{% include "partials/pagination.html" %}

The credit due is the line value plus its tax, less the restocking fee — the tax rate is carried across from the sold line, because a refund that quietly drops the VAT under-credits the customer and nobody notices until they count the money. The figure is computed live; the return only stores it when a credit note is actually drafted, so nothing on the record claims a credit was issued while this page is only proposing one.

A credit-only return has no goods coming back and therefore never gets a disposition row. A queue keyed on "what has been received" would drop it silently — perfectly valid work that looks abandoned — so this page branches on the return type instead, and those returns are settled from their approved quantities.
