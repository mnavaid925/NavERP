Duty Tariffs

Supply Chain›Duty Tariffs

The customs rate book: an HS/HTS code, a country of origin and a date window, and the duty percentage that applies to the three of them together. Duty is not a sales tax and cannot be stored as one — it turns on where the goods were made and on when they cleared, neither of which a sales-tax code has anywhere to put. Sales, VAT and GST stay in Accounting's tax codes; this register only covers what customs charges.

No duty tariffs

The rate book is empty, so a duty charge on a landed cost voucher has nothing to default from and has to be typed in each time. Add a line for each HS/HTS code you import under: give it a start date, leave the country of origin blank for the general rate, and add origin-specific rows on top of it where a trade agreement or an anti-dumping order changes the figure. If you were expecting rows here, try clearing the filters.
