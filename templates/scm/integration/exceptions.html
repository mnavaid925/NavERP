{{ append_only_note }}

Reprocessing clears the error text and returns the row to Pending — it does not resend anything, because 4.19 ships no outbound transport. It records that somebody has decided this exchange should be handled again, and it is the only write any screen in this sub-module makes to the exchange log. Nothing here edits or removes a row: if a row looks wrong, that is what the log says happened, and the corrected document is appended alongside it.
