      {% if obj.signature %}
        
{{ obj.signature }}

        
The HMAC a subscriber recomputes over the payload to satisfy themselves the push came from here and arrived unaltered.

      {% else %}
        

          Not computed — outbound transport is deferred. This is the design, not a gap. Signing a payload needs the plaintext signing key, and a subscription stores only a prefix and a one-way hash of its secret — enough to show that a secret is registered and to recognise which one, and mathematically insufficient to sign with. That trade is correct here precisely because nothing is delivered: 4.19 ships no HTTP client at all, so there is no push to sign and no liability in holding a key that could. The first pass that adds real delivery has to solve both halves together — reversible encrypted-at-rest storage for the key, and the transport that uses it — and this column is where the result lands.
        

      {% endif %}
