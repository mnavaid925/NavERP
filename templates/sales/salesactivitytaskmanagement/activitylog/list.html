That is the visible proof of the L36 ruling: 8.8 extends CRM 1.5's interaction stack and declares no second one. FK filter selects compare with `|stringformat:"d"` — NEVER `|slugify` on a pk (the house rule). Every enum control here is declared in `crud_list`'s `filters` spec, so every control rendered is a control the view actually applies (L54's third rule). Engagement is a DERIVED property (replied > clicked > opened > none) and never a filter: it is not a column, so there is nothing for a GET param to narrow on. {% endcomment %} {% block title %}Sales Activity{% endblock %} {% block content %}
