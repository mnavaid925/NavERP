{% extends "base.html" %} {% comment %} 8.8 Task Templates — the playbook register. A TaskTemplate does NOT declare a task. It GENERATES `crm.CrmTask` rows (CRM 1.5's table) when the Run action on its own page is used. There is no `class SalesTask` anywhere in this app, and the `task_type` / `priority` vocabularies on every row are IMPORTED from CRM 1.5 rather than re-spelled (L36) — so a generated task ranks identically to a hand-typed one. Every control rendered here is declared in `crud_list`'s `filters` spec, so every control is a control the view actually applies (L54's third rule). Badges are colour-named only (L33): green/red/amber/info/muted/slate exist; badge-success and badge-warning do NOT and render unstyled. {% endcomment %} {% block title %}Task Templates{% endblock %} {% block content %}
