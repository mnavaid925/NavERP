Territory managerThere is no manager field here on purpose. crm.Territory.manager is CRM 1.2's single accountable manager for a territory; a second management field on this register would be a second source of truth for the same fact.
Default member roleNone. Defaulting to "hunter" would let a roster of correctly-saved rows be completely wrong about what those rows mean — so the role is a declaration, not an inference.
Credit as moneyThe split is a percentage. 8.10 owns incentive compensation, and a stored "credit" figure here would be a second copy of a number another module owns.
Overlay subtreeAn overlay is an overlay alignment on the account plus an overlay specialist on the base territory. It is not a second territory tree, so there is no overlay parent to choose.
