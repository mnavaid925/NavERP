They are rendered here as a read-only receipt, and there is no input near them: a human must never be able to back-date a run's own receipt. Every verb is its OWN POST form with a csrf token and a confirm. Run is the commit that writes the assignment ledger; Toggle flips the rule in or out of force. A GET link must never change a coverage rule, so neither is a link. Run is offered only when `is_runnable` is true — the SAME predicate the view checks (active, has a target, inside its effective window), so the button and the refusal cannot disagree.
