A window here silences nothing. The services, alert rules and notification rules a window names are recorded scope: no alert engine, notification rule or permission check in this application reads them. Declaring that an outage is expected is a statement you make here; making it actually quiet is out of band.

A window needs both a start and an end — a one-ended window is a notice, and 0.17's incidents already own notices. Windows that have run are kept as history: an incident review a week later is exactly what needs them, so only a window that has not started can be deleted.
