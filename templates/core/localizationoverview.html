What this sub-module does NOT do. It does not translate the interface: the strings live in Django's gettext catalogues, and this platform ships no locale/ directory, so the languages registered here describe what is offered rather than what is translated. It does not fetch exchange rates — there is no feed and no scheduler. It does not convert any date or time on any other page: the registry records the zone, and applying it across the twenty apps that render dates is a separate change. And it does not transmit an e-invoice or file a return.
