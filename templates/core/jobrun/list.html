{% comment %} There is deliberately NO "Add run" button and no create route. A run is written by the job's Run now action or by the seeder, never by a person filling in a form: a run somebody typed in is a claim that a dispatch happened, and this repository has no dispatcher. An edit form exists only to correct a recorded outcome, which is why `triggered_at` and `triggered_by` are off it. {% endcomment %}

Every run here is a record that a run was asked for, not evidence that work happened. NavERP has no scheduler, so every row written by this build is a dry run.
