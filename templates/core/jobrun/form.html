There is no way to create a run from this page. A run is written by a job's Run now action or by the seeder, because a run somebody typed in is a claim that a dispatch happened and this repository has no dispatcher. This form only corrects an outcome already recorded.

Not on this form: triggered_at, triggered_by and is_dry_run — the first two are stamped by the action that requested the run, so the register cannot be edited into claiming a different requester or time. The third defaults to true and nothing in this application can clear it: there is no dispatcher, so every run recorded here is a dry run and a checkbox that could uncheck it would let this form assert an execution that never happened.
