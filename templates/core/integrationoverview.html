What this module does NOT do

No API is exposed. The credential verifier and the api_credential_required decorator are real and tested, but no API views ship in 0.13 — a module opts in. No OAuth authorisation server: an oauth_client credential is recorded, and there is no token endpoint, no authorisation-code flow and no refresh. No rate limiting is enforced — the policy is recorded and a view must apply the check. No connector marketplace backend: the catalogue indexes the per-module connector models; nothing installs anything. No scheduled execution and no retry/dead-letter handling — the repo has no scheduler and no outbound worker. No throughput or latency metrics. Declared here rather than implied.
