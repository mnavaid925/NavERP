{% comment %} This page declares NO ticket table and NO knowledge base. Both already exist in two different apps, and a third copy of either would be exactly the parallel-schema bug L29 forbids. It reads crm.Case + crm.KbCategory + crm.KnowledgeArticle and hrm.HelpdeskTicket + hrm.HelpdeskCategory + hrm.KnowledgeArticle, and links to each of their own pages. Note there is no `KnowledgeBase` CLASS anywhere in this repository - the file of that name in crm defines a class called KnowledgeArticle. {% endcomment %}

One view over the two support desks this workspace already has: the customer queue in CRM and the internal employee desk in HRM. This page creates nothing, and it does not open, route, merge or escalate a ticket — a ticket belongs in the queue that owns it, and the links below go there.
