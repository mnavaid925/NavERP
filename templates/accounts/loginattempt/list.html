Security overview

Every sign-in attempt with the heuristic risk score it earned. The score is not a model: it is three observable signals — an unseen public IP, an unseen device, and recent failures for the same identifier. There is no geo-IP lookup and no behavioural baseline. Nothing is blocked on it; a user with a second factor is challenged, and everyone else is flagged here for an admin to act on.
