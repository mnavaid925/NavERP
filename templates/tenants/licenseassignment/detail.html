What this page does not do

NavERP records commercial terms somebody wrote down. It does not enforce them.

Seat auto-deprovisioning is declined. Reclaiming this seat does not disable the login of the person who held it. There is no identity sync in NavERP, so the account, the password and access to every other module stay exactly as they are. The button records a commercial fact and stamps two evidence fields — that is all it does.

The converse also holds: this seat does not grant access. Nothing consults it when a request is made, so recording a seat does not open a module to anybody.

Expired is derived from expires_on, never stored — no code writes status="expired", which is why a seat can read Active and still be past its end date.
