What this page does not do

NavERP records commercial terms somebody wrote down. It does not enforce them.

The read order above is how a human reads this page — it is not a rule NavERP applies. No code consults a PlanEntitlement at request time, so the override does not override anything: entitlement enforcement is declined by this sub-module, and a grant is a record, not a gate. Writing privilege_value = true here grants a customer no capability by itself.

There is also no plan versioning and no grandfathering: a plan is a core.Tenant.PLAN_CHOICES value with no version, so a price change is an edit to these rows rather than a new plan tier that past subscriptions keep.
