How to read this register

A row with no subscription is the plan-level grant every customer on that plan receives. A row with one subscription is that single subscription’s override — the one that differs. Where both exist, the override is what a human reads first; the detail page shows it in that order.

NavERP records commercial terms somebody wrote down. It does not enforce them. Nothing consults a PlanEntitlement at request time. A grant is a record, not a gate, and the override precedence described above is a reading convention, not an implemented rule — entitlement enforcement is declined by this sub-module. A blank privilege_value means “this plan is not granted the feature”, which is a real answer; it is not the same as having no row.
