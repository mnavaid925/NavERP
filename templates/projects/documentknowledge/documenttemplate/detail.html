What this register is, and is not

{% comment %} Two honest limits, stated where somebody would otherwise assume otherwise. First: the format lock is an INTENT a human reads. Nothing in this sub-module enforces authorship or formatting, so no page may claim it does. Second: there is no "generate a document from this standard" affordance, because stamping project data into a standard is an authoring engine (Module 13.1) — the closest honest verb this pass ships is the download above. {% endcomment %}
Format lock
{% if obj.is_format_locked %} Recorded as frozen by policy. This is an intent the PMO notes, not an enforcement: nothing in this sub-module stops anyone editing a copy of the file. {% else %} No format lock recorded. {% endif %}
Generating from it
Not offered here. Merging project data into a standard — merge fields, locked formatting, co-editing — is an authoring engine and belongs to Module 13.1. Downloading the file and filling it in is the honest workflow at this stage.
Version chain
None, deliberately. A standard is not a controlled project record: re-publishing edits this row. Attaching one to a project copies it into the document register, where the revision chain and retention then apply to the copy.
Where a project uses it
A project that adopts this format registers its own copy as a document. The standard stays one row here for the whole organisation.
