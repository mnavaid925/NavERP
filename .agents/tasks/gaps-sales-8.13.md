## 3. Explicitly Declined (not gaps — settled decisions, recorded so they are not re-litigated)

| Declined | Reason |
|---|---|
| A `Campaign` / `Lead` / `Opportunity` / `Account` / `Content` table | L36/L37 — the spine owns them; 8.13 extends by FK. |
| A stored campaign-ROI / cost-per-lead / pipeline column | A derived fact stored beside its sources is a field that drifts. Computed on the console. |
| A stored acceptance-rate or SLA-compliance counter | Same reason: derived from the handoff rows so it cannot claim a rate its own history does not support. |
| `EventRegistration` as a numbered document | It is an attendance/membership row, not a document — the same ruling as `crm.CampaignMember`. It carries a tenant FK and timestamps and no number. |
| A second console for each of the five bullets | One console aggregates all five, which is what an operator reads first. The five entity lists remain the drill-down. |
